=== Clocka ===
The website theme for clocka.co.uk.

== Installing ==
1. In WordPress go to Appearance > Themes > Add New Theme > Upload Theme.
2. Choose clocka.zip, click Install Now, then Activate.
3. Go to Settings > Reading and choose "Your latest posts" (the theme's
   home page shows automatically on the front page).

== Settings ==
Appearance > Customize > Clocka:
- App Store link and Google Play link. Leave one empty to show "Coming soon".
- Premium monthly and yearly prices, and the free trial length.
- Contact email, privacy policy link, and the founder's story.

Appearance > Customize > Site Identity > Site Icon: upload
assets/img/site-icon.png if you'd like WordPress to manage the browser icon
(the theme already uses it when no Site Icon is set).

Appearance > Menus: an optional "Footer links" menu adds extra links in the footer.

== Store badges ==
The download buttons are plain text buttons. If you prefer Apple's and Google's
official badges, they can be swapped in later; both companies require their
official artwork rather than home-made versions with their logos.
